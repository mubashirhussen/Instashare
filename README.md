# InstaShare 📸✨

A full-stack Instagram-style social media platform built with React, Vite, and modern web aesthetics.

---

## 🌟 Key Features

- **🔐 Dynamic User Authentication & Registration**:
  - Sign In & Sign Up with persistent credentials stored securely.
  - Clean registration flow (Full Name, Username, Password) with instant profile generation.

- **📁 Direct File & Media Upload (`+ Create`)**:
  - Native file explorer picker & drag-and-drop support for photo posts and video reels directly from your device documents.
  - Live media previews with captioning, hashtags, and instant feed & profile synchronization.

- **🎬 5:5 Grid Video Reels**:
  - Side-by-side 5-column grid featuring 25+ curated learning and creator video reels (React 19, Python, Java DSA, System Design, Node.js, TypeScript, Docker, and more).
  - Tap-to-play video playback, mute/unmute audio controls, views/like counters, and fullscreen inspection modals.

- **🔍 Live Instant Profile Search**:
  - Real-time search dropdown in the header locating user profiles, creators, and accounts on keystroke.

- **💬 Intelligent Direct Messages**:
  - Real-time chat interface with active threads and intelligent conversational replies covering tech, programming languages, React, Node.js, Express, databases, and system design.

- **👤 Profile Page**:
  - Animated note bubble, verified creator badge, story highlights, follower metrics, and functional tabs: `POSTS`, `REELS`, `SAVED`, and `TAGGED`.
  - In-app profile editing modal (Name, Bio, Profile Picture, Website).

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 5, Vanilla CSS Design System
- **Icons**: React Icons (`react-icons`)
- **State & Storage**: Browser LocalStorage & Cookies (`js-cookie`)
- **Media**: HTML5 Video, Canvas & Responsive Media Handling
- **Deployment**: GitHub Pages via GitHub Actions

---

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
